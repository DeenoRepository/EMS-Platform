# K4.3 — Декомпозировать проверку LDAP-аутентификации администратора

## Problem

Повторное измерение после K4.1/K4.2 показывает, что `handleTestLdapAuth` в
[`apps/web/src/app/setup/page.tsx`](../../apps/web/src/app/setup/page.tsx:259)
сохраняет реальную complexity `cx 13` при 43 строках. Это наиболее приоритетный
не закрытый кандидат среди проверенных бизнес-обработчиков: он содержит
response mapping для успешной LDAP-проверки, ошибки API, network error и
условное заполнение имени/email администратора.

## Scope

- Вынести только pure response/state mapping успешного и неуспешного результата
  `POST /api/setup/test-ldap` в соседний модуль.
- Сохранить URL, HTTP method, request payload, сообщения, `ldapAuthVerified`,
  значения по умолчанию имени/email и loading-state semantics.
- Добавить focused unit-тесты для success с профилем, success без профиля,
  API error и network-error mapping.
- Не менять LDAP API route, security/rate limiting, `handleTestLdap`, setup
  execution, UI presentation или K6.

## Verified map

- [KNOWN] Единственный consumer обработчика — `onTestLdapAuth={handleTestLdapAuth}`
  в [`SetupAdminLdapStep.tsx`](../../apps/web/src/components/setup/SetupAdminLdapStep.tsx:66).
- [KNOWN] Обработчик вызывает только `/api/setup/test-ldap` методом `POST` и
  применяет ответ к локальным setup setters.
- [KNOWN] LDAP endpoint возвращает `success`, `message`, `error` и optional
  `user` согласно [`test-ldap/route.ts`](../../apps/web/src/app/api/setup/test-ldap/route.ts:60).
- [KNOWN] В существующих тестах нет прямого теста setup page; unit-тесты
  запускаются через [`scripts/test-runner.mjs`](../../../scripts/test-runner.mjs:27).
- [KNOWN] Новая dependency не требуется; helper использует только TypeScript
  types and callbacks.

## Steps

1. Вынести минимальный pure helper для применения LDAP auth response.
2. Перенаправить `handleTestLdapAuth` на helper, не меняя fetch flow.
3. Добавить focused tests для всех response branches и default-field rules.
4. Повторно измерить complexity и запустить targeted/full test, lint, web tsc и
   quality baseline.
