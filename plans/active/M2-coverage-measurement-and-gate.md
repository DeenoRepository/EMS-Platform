# M2 — Измерять покрытие тестами и закрепить его порогом в CI

## Problem

Покрытие в проекте не измеряется. Ни `c8`, ни `nyc`, ни встроенный
`--experimental-test-coverage` не подключены: проверено по `package.json`
всех пакетов и по
[`scripts/test-runner.mjs`](../../scripts/test-runner.mjs). В
[`ci.yml`](../../.github/workflows/ci.yml) 12 гейтов — покрытия среди них нет.

Это единственная неизмеряемая характеристика качества: 8 остальных
жёстко зафиксированы порогами в
[`check-quality-baseline.mjs`](../../scripts/check-quality-baseline.mjs).
Следствие — удаление или отключение теста не заметит ни один гейт.

Разовое измерение при инспекции дало: охват **11.7 %** файлов, **92.7 %**
строк кодовой базы не исполняется ни одним тестом. Подробности и метод —
[`2026-08-31-test-coverage-inspection.md`](../../docs/quality/inspections/2026-08-31-test-coverage-inspection.md) §1–2.

**Ловушка при реализации:** итоговая строка `all files` в отчёте
`--experimental-test-coverage` показала `80.25 %`, но это доля строк
**только среди загруженных тестами файлов**. Файл, который никто не
импортировал, в отчёт не попадает вообще. Публиковать это число как
«покрытие проекта» нельзя — оно завышает реальность в семь раз.

## Scope

**Изменяется:** [`test-runner.mjs`](../../scripts/test-runner.mjs) получает
режим сбора покрытия; появляется скрипт-гейт с порогами; шаг добавляется в
[`ci.yml`](../../.github/workflows/ci.yml); метрики попадают в
генерируемый отчёт.

**Не изменяется:**
- Обычный `pnpm test` остаётся быстрым — покрытие включается отдельной
  командой/флагом, а не по умолчанию.
- Пороги из
  [`check-quality-baseline.mjs`](../../scripts/check-quality-baseline.mjs)
  не трогаются: у покрытия собственные пороги и собственный источник
  истины.
- Новые тесты в этой story не пишутся — только измерение. Наращивание
  покрытия — `M3`–`M6`.

**Зависимость:** выполняется после [`M1`](M1-test-runner-discovers-all-tests.md),
иначе базовая линия будет снята по неполному набору тестов.

## Steps

1. Добавить в [`test-runner.mjs`](../../scripts/test-runner.mjs) флаг
   `--coverage`, пробрасывающий `--experimental-test-coverage`. Внешних
   зависимостей не добавлять: Node 22 умеет это нативно.
2. Написать `scripts/check-coverage.mjs`, который:
   * считает **обе** метрики — долю строк среди загруженных файлов и
     охват файлов относительно всех production-файлов (`.ts`/`.tsx` без
     `.test.`/`.d.ts`);
   * сравнивает с порогами, объявленными константами в этом же файле
     (единственный источник истины, как у
     [`check-quality-baseline.mjs`](../../scripts/check-quality-baseline.mjs));
   * поддерживает `--report` для генерации
     `docs/quality/COVERAGE_BASELINE.md`.
3. Зафиксировать стартовые пороги по факту после `M1` — «храповиком», без
   запаса вверх: цель гейта на этом шаге — запретить деградацию, а не
   заставить дописывать тесты.
4. Перенести из
   [`check-quality-baseline.mjs`](../../scripts/check-quality-baseline.mjs)
   приём сохранения даты `Measured at:` при неизменных метриках — иначе
   шаг `git diff --exit-code` в CI будет краснеть при смене календарной
   даты (этот дефект уже ловили, см.
   [`2026-08-31-inspection.md`](../../docs/quality/inspections/2026-08-31-inspection.md) §2.2).
5. Добавить в [`ci.yml`](../../.github/workflows/ci.yml) шаг запуска гейта
   и шаг проверки актуальности отчёта.
6. Сослаться на новый отчёт из [`docs/README.md`](../../docs/README.md) и
   [`scripts/README.md`](../../scripts/README.md).

## Definition of Done

- [ ] `pnpm test` без флага не собирает покрытие и не замедлился.
- [ ] `node scripts/check-coverage.mjs` печатает обе метрики и корректно
      падает при их снижении ниже порога (проверено искусственным
      занижением).
- [ ] `docs/quality/COVERAGE_BASELINE.md` генерируется; повторный запуск
      при неизменном коде оставляет `git diff` чистым.
- [ ] В отчёте явно разделены «строки среди загруженных файлов» и «охват
      файлов»; ни одно число из них не продублировано в других
      markdown-файлах.
- [ ] CI содержит шаг проверки покрытия.
- [ ] Полный гейт зелёный.

## Result

Заполняется при закрытии story.
